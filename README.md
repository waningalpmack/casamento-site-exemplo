# 💍 Rafael & Sofia

> Site de casamento com contagem regressiva, galeria interativa, formulário RSVP, modo noturno e suporte multilíngue.

🌐 **Website:** https://www.pablogdev.com.br  
🚀 **Demo:** https://pablog-7.github.io/rafael-sofia-wedding/

---

## 🎯 Sobre o Projeto

O **Rafael & Sofia** é um UI Concept de um site de casamento desenvolvido para compor meu portfólio de desenvolvimento front-end. O projeto apresenta uma experiência completa para convidados com contagem regressiva para o grande dia, galeria de fotos interativa, formulário de confirmação de presença (RSVP), modo noturno e suporte a três idiomas (Português, Inglês e Espanhol).

Desenvolvido com HTML, CSS e JavaScript puro, este conceito demonstra a criação de sites institucionais elegantes e funcionais para eventos especiais.

## ⚡ Funcionalidades

### 🏠 Página Inicial

- Hero com imagem de fundo em desktop
- Título principal com fonte cursiva
- Data do casamento em destaque
- Contador regressivo em tempo real
- Seções "Nossa História" e "RSVP" com chamadas para ação
- Botões de navegação para outras páginas

### 💑 Quem Somos

- História do casal com detalhes
- Como tudo começou em 2017
- Imagem lado a lado com o texto
- Texto emocionante sobre a trajetória do casal

### 📅 Dia do Casamento

- Informações detalhadas sobre o evento
- Cerimônia Religiosa
- Festa para família e amigos
- Código de vestimenta
- Estacionamento
- Data exata (em breve)
- Mapa interativo com localização

### 🖼️ Galeria

- Grid de fotos do casal
- Efeito hover com zoom e lupa
- Lightbox para visualização ampliada
- 6 fotos com transições suaves
- Carregamento lazy das imagens

### 📝 RSVP (Confirmação de Presença)

- Formulário completo com validação
- Nome completo e e-mail
- Opção de presença (Sim/Não)
- Número de acompanhantes
- Campo para mensagem personalizada
- Integração com FormSubmit
- Fallback para envio por e-mail

### 🌙 Modo Noturno

- Alternância via Floating Action Button
- Cores invertidas para conforto visual
- Persistência no localStorage
- Ícone dinâmico (🌙/☀️)

### 🌍 Multilíngue

- Suporte a 3 idiomas: Português, Inglês, Espanhol
- Seleção via Floating Action Button
- Tradução de todos os textos da interface
- Persistência no localStorage

### 🧭 Navegação

- Menu fixo com links para todas as páginas
- Menu hambúrguer responsivo
- Indicação visual da página ativa
- Scroll suave entre as seções

- **Paleta Elegante** - Dourado (#e6b255), branco e tons neutros

## 💼 Sobre este Case

Este projeto faz parte da coleção de **UI Concepts** desenvolvidos para meu portfólio. O objetivo é demonstrar minha abordagem na criação de sites para eventos especiais, com foco em design elegante, experiência do usuário e funcionalidades completas como RSVP e contagem regressiva.

Caso deseje transformar este conceito em uma aplicação real, ele pode ser expandido com React, TypeScript, Next.js, backend, banco de dados e integrações personalizadas.
